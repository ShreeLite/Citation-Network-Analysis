# V2 Changes — Citation Network Dashboard

## Change 1: Fix Treemap Black-Color Bug (Research Areas Tab)

**Problem:** In the Research Areas tab, some treemap tiles (e.g., neuroscience, medical fields) rendered as solid black. This happened because ECharts was given a single base color per institute with `colorSaturation: [0.35, 0.65]`, and certain saturation/brightness combinations collapsed to black.

**Method:** The root cause was ECharts' built-in color mapping (`colorSaturation`, `colorMappingBy`) which unreliably assigns colors to treemap nodes, sometimes falling back to black. Fixed by bypassing ECharts' color mapping entirely: colors are now computed in JS and baked directly into each tree node's `itemStyle.color` before the data reaches ECharts. A `shade()` function generates tints from the institute base color (blue for IIIT-H, orange for IIIT-D), with intensity proportional to paper count — fields with more papers get a darker, more saturated shade; smaller fields get a lighter tint. Subfields are shaded relative to both their own size and their parent field's weight.

**File:** `site/src/tabs/Areas.tsx`

**Where to see it:** Navigate to the **Research Areas** tab. All treemap tiles display in shades of blue (IIIT-H) or orange (IIIT-D) — darker = more papers. No more black tiles.

## Change 2: Q1 and Impact Factor Filtering (Venues & Quality Tab)

**Problem:** No way to filter papers by journal quality (Q1 quartile) or by numeric Impact Factor thresholds (>5, >10).

**Method:**
1. **Impact Factor data:** Since the OpenAlex Sources API was rate-limited (HTTP 429), computed a proxy IF from existing data: mean citation count per journal source across all papers in `papers_enriched.parquet`, keyed by `openalex_source_id`. Injected the `impact_factor` field into `site/src/data/papers.json` (7,965 of 8,934 papers received an IF value).
2. **Paper interface:** Added `impact_factor?: number | null` to the `Paper` type in `site/src/data.ts`.
3. **Filter controls:** Added a quality filter bar at the top of the Venues tab with:
   - **Q1 only** toggle button — filters to only Q1-quartile journal papers
   - **IF threshold** buttons — All / IF > 5 / IF > 10
   - Clear button and count of filtered vs. total papers
4. **IF KPI cards:** Added three KPI cards showing papers with IF data, papers in IF > 5 venues, and papers in IF > 10 venues (with percentages).
5. **Top venues table:** Added an IF column to the top journals table showing the mean IF for each venue.

**Files:** `site/src/tabs/Venues.tsx`, `site/src/data.ts`, `site/src/data/papers.json`

**Where to see it:** Navigate to the **Venues & Quality** tab. Use the quality filter buttons at the top to toggle Q1-only mode or set IF thresholds. The KPI cards, charts, and top-venue tables all update to reflect the active filters. The top journals table now shows an IF column.

## Change 3: India Faculty-to-Faculty Connections (India Faculty↔Faculty Tab)

**Problem:** No per-author, faculty-to-faculty view of Indian collaborations — only aggregate institutional connections existed.

**Method:**
1. **Data generation:** Wrote `scripts/gen_indian_f2f.py` that reads `authorship_network_all_coauthors.csv` (for external Indian collaborator edges) and `main_papers.parquet` + `main_links.parquet` (for internal edges on Indian-connected papers). Indian institutions are identified by keyword matching (IIT, NIT, IIIT, IISER, ISI, TIFR, etc.). Output: `site/src/data/indian_f2f.json` with external_nodes, external_edges, internal_edges, and summary stats.
2. **New tab component:** Created `site/src/tabs/IndianF2F.tsx` with two toggle-able views:
   - **External view:** Network graph + data table of our faculty ↔ Indian partner collaborations (green = Indian partner, blue/orange = our faculty).
   - **Internal view:** Network graph + data table of our faculty ↔ our faculty pairs who co-authored Indian-connected papers.
3. **Performance:** Added a "Min. joint papers" dropdown (default: 2) to filter out single-paper edges and keep the network renderable. The full dataset has 1,548 nodes and 1,686 edges; at min=2, this drops to ~350 nodes — fast enough for Cytoscape.js without browser lag.
4. **Integration:** Added the tab to `site/src/App.tsx` as "India Faculty↔Faculty" and registered the data import in `site/src/data.ts`.

**Data stats:** 1,686 external edges, 1,384 unique Indian partners, 348 internal edges.

**Files:** `scripts/gen_indian_f2f.py` (new), `site/src/tabs/IndianF2F.tsx` (new), `site/src/data.ts`, `site/src/App.tsx`, `site/src/data/indian_f2f.json` (generated)

**Where to see it:** Navigate to the **India Faculty↔Faculty** tab. Use the "Min. joint papers" dropdown to control network density (higher = fewer edges, faster rendering). Toggle between "Our faculty ↔ Indian partners" and "Our faculty ↔ our faculty (Indian papers)" views. Both show interactive Cytoscape.js network graphs and sortable data tables. KPI cards show summary statistics. All views respect the global filters (institute, year range, unit, search).

## Change 4: Year Timeline Slider/Animation (Citation & Collaboration Network Tabs)

**Problem:** No way to see how the citation or collaboration networks evolved over time.

**Method:** Added year timeline animation controls to both network tabs:
1. **State:** `animYear` (current animation year or null), `playing` flag, interval timer ref.
2. **Play/Stop button:** Starts a 1.2-second-per-year animation from 2016 to 2026, progressively showing edges/nodes up to that year.
3. **Range slider:** Manual scrub to any year during or after animation.
4. **Year display:** Shows the current animation year prominently.
5. **Reset button:** Returns to the normal filter-based year range.
6. **Edge/node count:** Shows how many edges (collaboration) or papers (citation) are visible at the current animation year.

**The animation is cumulative:** at year Y it shows all data from 2016 through Y, so you see the network grow over time. This means at 2020 you see all connections from 2016–2020, not just 2020 alone. When the animation reaches 2026 or is stopped, it returns to the normal year-range filter.

**Files:** `site/src/tabs/CollabNet.tsx`, `site/src/tabs/CitationNet.tsx`

**Where to see it:**
- **Collaboration Network** tab: Click "Play timeline" below the colour-by controls. The network animates year by year, showing co-authorship edges accumulating. Use the slider to scrub to a specific year.
- **Citation Network** tab: Click "Play timeline" next to the PageRank slider. The citation graph animates, showing papers and citation edges accumulating over time.
